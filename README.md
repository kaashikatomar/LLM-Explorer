## ✨ Key Features

### 📚 1. Six In-Depth Curriculum Modules
1. **Introduction to AI & LLMs**: AI/ML/DL hierarchy, deterministic code vs. probabilistic neural networks, and foundation models.
2. **Tokenization & Text Processing**: Why computers need numbers, Byte Pair Encoding (BPE), and Token IDs.
3. **Embeddings & Vector Representations**: High-dimensional semantic space, vector geometry, and $King - Man + Woman = Queen$.
4. **Attention Mechanisms & Transformers**: Contextual disambiguation ("river bank" vs. "financial bank"), Query-Key-Value (Q, K, V), and Self-Attention.
5. **Next-Token Prediction & Probability**: The autoregressive generation loop, unnormalized logits, and Softmax normalization.
6. **Temperature & Text Generation**: Temperature scaling ($T$), greedy decoding vs. creative sampling, and entropy control.

### 🔬 2. Five Interactive Playgrounds
- **🔤 Tokenizer Playground**: Type custom text to inspect real-time subword splits, token counts, and deterministic Token IDs.
- **🧭 Vector Embeddings Playground**: Compare 5D feature vectors across concepts and compute mathematical Cosine Similarity.
- **🔍 Self-Attention Playground**: Click words in test sentences to visualize contextual attention heatmaps and dynamic weights.
- **🔮 Next-Token Prediction Simulator**: Step through candidate token distributions and build sentences one token at a time.
- **🌡️ Temperature Playground**: Adjust an interactive slider ($0.0$ to $2.0$) to watch the probability curve sharpen or flatten live.

### 🎥 3. Verified Educational Video Library
Embedded masterclasses from top AI educators:
- **Andrej Karpathy**: *[1hr Talk] Intro to Large Language Models* & *Let's build the GPT Tokenizer*
- **3Blue1Brown (Grant Sanderson)**: *Attention in transformers, step-by-step* & *Visual intro to transformers*
- **StatQuest (Josh Starmer)**: *Word Embedding and Word2Vec* & *Transformer Neural Networks*

### 📝 4. 30-Question Interactive Quiz Arena
- Questions graded across **Beginner**, **Intermediate**, and **Advanced** difficulty tiers.
- Immediate answer validation with comprehensive explanations.
- Automatic score calculation and persistent best-score storage.

### 📖 5. Searchable AI Glossary (32 Terms)
- Searchable directory of foundational terminology from *Artificial Intelligence* and *Backpropagation* to *Logits*, *Temperature*, and *Hallucination*.
- Filterable by categories and alphabetical indexing.

### 💾 6. Browser-Based Progress Persistence
- Automatically remembers completed lessons and quiz results using `localStorage`.
- Reset progress option with confirmation modal.
- Subdirectory and custom domain safe with hash-based deep linking (`#dashboard`, `#learn`, `#quiz`, etc.).
